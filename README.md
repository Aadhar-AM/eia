# Eklavya International Academy Website

This is the official website for Eklavya International Academy, a premier educational institution committed to providing excellence in education.

## Features

- Modern and responsive design
- Comprehensive information about academic programs
- Student achievements showcase
- Contact information
- Faculty details
- Facilities overview

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Font Awesome icons

## Live Website

Visit our website at: [Eklavya International Academy](https://aadhar-am.github.io/eia/)

## Local Development

To run this website locally:

1. Clone the repository

```bash
git clone https://github.com/Aadhar-AM/eia.git
```

2. Open `index.html` in your web browser
